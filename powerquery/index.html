Power Query (M)

Receitas de consultas prontas para preencher, catálogo de funções da linguagem M e um formatador que organiza o código e explica cada passo. Tudo roda no seu navegador: nada do que você digita é enviado a lugar nenhum.

Conceitos essenciais (leia uma vez, ajuda em tudo)
Onde colar o código
No Excel: Dados → Obter Dados → Iniciar o Editor do Power Query; no Power BI: Transformar dados. Com a consulta selecionada, abra Página Inicial → Editor Avançado e cole. As receitas de Fontes de dados são consultas completas; as demais geram um passo para colar antes do in.
Passos e let … in
Uma consulta M é uma lista de passos entre let e in. Cada passo usa o anterior; o que vem depois do in é o resultado. Passos são separados por vírgula, menos o último. Ao colar um passo novo, aponte o in para ele (ou para o passo que vier depois).
Maiúsculas importam
M diferencia maiúsculas de minúsculas: Table.SelectRows funciona, table.selectrows não. Palavras como let, in, each, if, then, else, true e null são sempre minúsculas. Nomes de colunas também.
Sempre vírgula, em qualquer idioma
Diferente do Excel e do DAX, o código M não muda com a região: argumentos são separados por vírgula e o decimal é ponto (1234.5). O que muda é só a interface do editor. Por isso esta página não tem chave de idioma.
each e colchetes
each [Valor] > 100 é um atalho: o each cria uma função da linha atual e [Valor] lê o campo da linha. Listas usam chaves { } e registros usam colchetes [ ].
Nomes com espaço
Passos e colunas com espaços ou acentos precisam de aspas: #"Nome do passo". Em each, o nome da coluna fica entre colchetes sem aspas: [Nome do Cliente].
Tipos de dados
Depois de importar, defina os tipos (type text, type number, type date, Int64.Type). Valores vindos como texto em formato brasileiro (31/12/2025, 1.234,56) precisam da cultura "pt-BR" na conversão.
Segredos
Nunca coloque senha ou token dentro do código da consulta: ele vai junto com o arquivo. Use as credenciais da própria fonte de dados.
O código é analisado aqui mesmo, no navegador. Nada é executado.
