PySpark

Receitas de código prontas para preencher, catálogo de funções e um formatador que organiza o código e explica cada passo. Serve para notebooks do Microsoft Fabric, Databricks e Spark. Tudo roda no seu navegador: nada do que você digita é enviado a lugar nenhum.

Conceitos essenciais (leia uma vez, ajuda em tudo)
Onde rodar
Em um notebook de PySpark: no Microsoft Fabric (notebook ligado a um Lakehouse), no Databricks, no Synapse ou em um Spark local. Nos notebooks a variável spark já existe. Esta página só gera e explica o código: ela não executa nada.
Imports de sempre
from pyspark.sql import functions as F dá acesso a F.col, F.sum, F.when e às demais funções. from pyspark.sql.window import Window serve para janelas e from pyspark.sql import types as T para tipos. Evite from pyspark.sql.functions import *: ele esconde sum, min, max e round do Python.
DataFrames não mudam
Cada transformação (filter, withColumn, join…) devolve um DataFrame novo. Guarde o resultado em uma variável: df = df.filter(...). Chamar df.filter(...) sozinho não altera df.
Execução preguiçosa
As transformações só montam um plano. O trabalho acontece nas ações: show, count, collect e write. Por isso um erro numa linha pode aparecer só na ação seguinte.
Colunas: texto ou F.col
Muitos métodos aceitam o nome entre aspas (select("valor")). Para calcular ou comparar, use F.col("valor") > 100 ou df["valor"]. Constantes entram com F.lit(0).
Condições: & | ~
Em colunas, use & (e), | (ou) e ~ (não), nunca and, or e not. Cada condição vai entre parênteses: (F.col("a") > 1) & (F.col("b") == "x"). Para vazios use isNull(), nunca == None.
Formatos de data
Os padrões seguem o Java: yyyy ano, MM mês, dd dia, HH hora, mm minuto, ss segundo. MM maiúsculo é mês; mm minúsculo é minuto. Datas brasileiras: "dd/MM/yyyy".
Segredos
Nunca escreva senha ou token no notebook. Busque de um cofre (no Fabric, notebookutils.credentials.getSecret; no Databricks, dbutils.secrets.get).
Cuidado com collect e toPandas
Eles trazem todas as linhas para a memória de uma única máquina. Em tabelas grandes derrubam o notebook. Filtre, agregue ou use limit antes.
